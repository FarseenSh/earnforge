`@earnforge/cli` is a full-featured command-line interface wrapping `@earnforge/sdk`. Every
command supports `--json` for machine-readable output.

## Installation

<Tabs>
  <TabItem label="npm (global)">
    ```bash
    npm i -g @earnforge/cli
    ```
  </TabItem>
  <TabItem label="npx (one-shot)">
    ```bash
    npx @earnforge/cli list --asset USDC
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add -g @earnforge/cli
    ```
  </TabItem>
</Tabs>

| Variable | Required | Description |

| `LIFI_API_KEY` | For `quote` only | LI.FI Composer API key for deposit quotes |

## Commands

### earnforge list

List vaults with optional filters.

```bash
earnforge list --asset USDC --chain 8453 --min-tvl 1000000 --sort apy --limit 10
earnforge list --strategy conservative --json
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--chain <id>` | number | all | Filter by chain ID |
| `--asset <sym>` | string | all | Filter by asset symbol |
| `--min-apy <n>` | float | none | Minimum APY (as fraction, e.g. 0.05 = 5%) |
| `--min-tvl <n>` | float | none | Minimum TVL in USD |
| `--sort <field>` | string | `apy` | Sort by `apy` or `tvl` |
| `--limit <n>` | number | `20` | Max results |
| `--strategy <preset>` | string | none | Strategy preset filter |
| `--json` | boolean | `false` | Output as JSON |

**Example output:**

```
  Slug                    Name                APY      TVL         Protocol   Chain
  ----                    ----                ---      ---         --------   -----
  morpho:8453:_:0xbeef...          USDC Base Vault     5.23%    $120.5M     aave    8453
  morpho:1:_:0xdead...             USDC Morpho         4.87%    $89.2M      morpho  1
  euler:42161:_:0xcafe...         USDC Arbitrum       4.12%    $45.0M      euler   42161

  Showing 3 vaults
```

### earnforge vault

Get detailed vault info by slug.

```bash

earnforge vault morpho:8453:_:0xbeef0e0834849acc03f0089f01f4f1eeb06873c9 --json
```

### earnforge quote

Build a deposit quote for a vault.

```bash
earnforge quote --vault morpho:8453:_:0xbeef... --amount 100 --wallet 0xYour...
earnforge quote --vault morpho:8453:_:0xbeef... --amount 100 --wallet 0xYour... --optimize-gas
earnforge quote --vault morpho:8453:_:0xbeef... --amount 100 --wallet 0xYour... --from-chain 1 --json
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--vault <slug>` | string | **required** | Vault slug |
| `--amount <human>` | string | **required** | Human-readable deposit amount |
| `--wallet <addr>` | string | **required** | Wallet address |
| `--from-token <addr>` | string | auto | Override source token address |
| `--from-chain <id>` | number | vault chain | Override source chain for cross-chain |
| `--optimize-gas` | boolean | `false` | Compare routes from multiple chains |
| `--json` | boolean | `false` | Output as JSON |

**Example output:**

```
Deposit Quote -- USDC Base Vault

  Amount:      100 (100000000 raw, 6 decimals)
  From:        USDC on chain 8453
  To:          USDC Base Vault on chain 8453
  Est. Output: 99850000
  Duration:    15s
  Gas Cost:    $0.02
  Fee Cost:    $0.10

Transaction ready to sign via quote.transactionRequest
```

With `--optimize-gas`:

```
Gas-optimized routes for USDC Base Vault

  Base (8453): gas=$0.02 fee=$0.10 total=$0.12 time=15s << cheapest
  Optimism (10): gas=$0.03 fee=$0.15 total=$0.18 time=30s
  Ethereum (1): gas=$2.50 fee=$0.10 total=$2.60 time=45s
```

<Aside type="caution">
The `quote` command requires the `LIFI_API_KEY` environment variable.
Without it, you will get a `ComposerError`.

### earnforge simulate

Simulate a deposit against the chain head using Composer's own simulator.

```bash
earnforge simulate --vault morpho:8453:_:0xbeef... --amount 1000 --wallet 0xYourAddress
earnforge simulate --vault morpho:8453:_:0xbeef... --amount 1000 --wallet 0xYourAddress --json
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--vault <slug>` | string | **required** | Vault slug |
| `--amount <human>` | string | **required** | Deposit amount, human-readable |
| `--wallet <addr>` | string | **required** | Wallet address |
| `--from-token <addr>` | string | the vault asset | Token to spend |
| `--slippage-bps <n>` | number | none | Slippage tolerance in basis points |
| `--allow-revert` | boolean | `false` | Return calldata even if the simulation reverts, with diagnostics |
| `--json` | boolean | `false` | Output as JSON |

This compiles through Composer and simulates against the chain head, so it observes
allowances, balances and protocol state. Exits non-zero on a simulated revert.

Earlier versions issued a bare `eth_call`, which cannot see any of that and reported
SUCCESS for transactions that would revert on submission.

### earnforge probe

Check whether one of LI.FI's newer route flags is actually served for a given pair.

`gasless` and Smart Deposits (`destinationAction`, which bridges and then deposits into an
ERC-4626 vault in one route) are both accepted by the live API and both fail by **exclusion**
rather than by error: when a flag cannot be honoured the route is dropped, and the response
is indistinguishable from a pair with no liquidity. This command runs the request with and
without the flag and tells you which of the two you are looking at.

```bash
# is gasless served for this pair?
earnforge probe --flag gasless \
  --from-chain 42161 --to-chain 8453 \
  --from-token 0xaf88d065e77c8cC2239327C5EDb3A432268e5831 \
  --to-token 0x833589fcd6edb6e08f4c7c32d4f71b54bda02913 \
  --wallet 0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045

# is this vault on LI.FI's Smart Deposits allowlist?
earnforge probe --flag smart-deposit --vault morpho:8453:_:0xbeef0e08... \
  --from-chain 42161 --from-token 0xaf88d065e77c8cC2239327C5EDb3A432268e5831 \
  --wallet 0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045
```

```
  gasless  42161 -> 8453

  Verdict:   flag-excluded
  Baseline:  routes
  Flagged:   no route
  Status:    404
```

| Option | Description |
|--------|-------------|
| `--flag <name>` | `gasless` or `smart-deposit` (required) |
| `--from-chain <id>` | Source chain ID (required) |
| `--from-token <addr>` | Source token address (required) |
| `--wallet <addr>` | Source address. Nothing is signed or sent (required) |
| `--vault <slug>` | Vault slug. Required for `smart-deposit` |
| `--to-chain <id>` | Destination chain. Defaults to the vault chain |
| `--to-token <addr>` | Destination token. Defaults to the vault underlying |
| `--amount <raw>` | Amount in smallest units. Default `10000000` |
| `--json` | Output as JSON |

**Verdicts**

| Verdict | Meaning |
|---------|---------|
| `supported` | The flag is served for this pair. |
| `flag-excluded` | The pair routes fine without the flag, and not with it. The flag is the cause. Means *not yet*, not *broken*. |
| `route-unavailable` | Neither request routes. The pair is dead and the flag is untested. |
| `rejected` | The API refused the request on shape, before routing. That is a caller bug. |

`flag-excluded` and `route-unavailable` are the same HTTP status and opposite conclusions,
which is the entire reason this command exists. It reports rather than falling back: retrying
without the flag succeeds while silently abandoning what you asked for. Exit code stays `0`
for an unserved flag, and `1` only for `rejected`.

The command refuses to probe two cases that would produce a false negative, because each
returns the same 404 as an unlisted vault: a `--to-token` that is not the vault's underlying,
and a same-chain route (destination actions are cross-chain EVM only).

See [Pitfall 25](/pitfalls/#pitfall-25----new-route-flags-fail-by-exclusion-not-by-error).

### earnforge init

Scaffold a new Next.js + wagmi + `@earnforge/react` project.

```bash
earnforge init my-yield-app
```

| Argument | Description |
|----------|-------------|
| `<name>` | Project name |

The scaffold filters verification-flagged vaults with the reason inline, shows risk
alongside APY, and keeps the API key in a Server Component: a scaffolder's output
becomes the pattern every new project copies.

## JSON Output

Every command supports `--json` to output structured JSON instead of formatted tables.
This is designed for piping into other tools, scripts, or CI pipelines.

```bash
earnforge top --asset USDC --limit 3 --json | jq '.[0].apy'
earnforge doctor --vault morpho:8453:_:0xbeef... --json | jq '.checks | map(select(.status == "FAIL"))'
```
